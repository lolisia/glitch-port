# Glitch Port Unity SDK

Unity client package for glitch-port, a Sentry-like error and crash reporting
platform for game engines.

The package supports Unity 2022.3 LTS and newer. It ships a precompiled
`GlitchPort.Core.dll` under `Runtime/Plugins`, built from
`sdk/dotnet/src/GlitchPort.Core` by `scripts/build-unity-plugins.sh` at the
repository root.

See [documents/sdk-unity.md](../../../documents/sdk-unity.md) for the full SDK
documentation.
